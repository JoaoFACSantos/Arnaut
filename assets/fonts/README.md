# Tipos de letra

Ficheiros WOFF2 alojados no próprio site (sem pedidos ao Google Fonts), com os subconjuntos
`latin` e `latin-ext` usados em português:

- **Newsreader** (variável, pesos 300–500, eixo ótico) — Production Type, SIL Open Font License 1.1
- **Manrope** (variável, pesos 300–700) — Mikhail Sharanda, SIL Open Font License 1.1
- **DM Mono** (300, 400, 500) — Colophon Foundry, SIL Open Font License 1.1

As declarações `@font-face` estão no início de `styles.css`.
